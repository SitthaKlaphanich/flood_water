❌ 3. ตัวอย่างกรณีทดสอบที่ไม่ผ่านเกณฑ์ (คัดออก ไม่นำเข้าแอป)

3.1 กล้อง JPEG Placeholder (29 กล้องใน Longdo คืนภาพเดียวกันขนาด 3,070 Bytes ซ้ำกัน)

ตัวอย่าง: ITICM_BMAMI0080 (เชิงสะพานตากสิน) - ระบบตรวจพบ SHA-256 ซ้ำกันกับอีก 28 กล้อง (d896d151...) ขนาด 3,070 bytes จึงถูกตัดออกทันที

สถานะ: ปฏิเสธ (ภาพ Placeholder ไม่มีเนื้อหาการจราจรจริง)
ตรวจจับโดย: Hash Deduplication & Minimum Variance Filter

3.2 DWR กรมทรัพยากรน้ำ (ติด Authentication ห้าม bypass)

- Endpoint รูปถ่าย POST https://telemetry.dwr.go.th/api/image/cctv คืนรหัส HTTP 403 Forbidden เมื่อไม่มี JWT Token จากระบบล็อกอินภายใน
- ลิงก์ตรงกล้อง Axis คืนรหัส HTTP 401 Unauthorized (Digest Auth) และมี credential ฝังใน URL ซึ่งเบราว์เซอร์สมัยใหม่บล็อก
